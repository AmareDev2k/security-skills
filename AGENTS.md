# Agent Guidance

## Repository purpose

This repository contains composable security skills for coding agents.

## Contribution rules

- Keep skills focused and independently usable.
- Preserve the `SKILL.md` frontmatter format: `name` and `description`.
- Prefer actionable, safe guidance over speculation.
- Do not include real credentials, private data, or destructive commands.
- Update the README when adding a user-visible skill or workflow.

## Validation

Before submitting changes:

- Check Markdown formatting.
- Validate JSON files.
- Run `git diff --check`.
