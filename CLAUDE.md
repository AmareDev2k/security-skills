# Claude Code Guidance

Use the security skills in this repository when a task involves application
security, authentication, secrets, dependencies, web configuration, or
incident response.

## Working style

- Read the relevant `SKILL.md` before applying a security workflow.
- Inspect the repository before making recommendations.
- State assumptions and distinguish confirmed findings from hypotheses.
- Prefer minimal, reversible changes.
- Never expose or reproduce secrets found during a review.
